# myvibedsdr
the most basic vibe sdr application

just a very bare bones vibe coded (with ChatGPT and rawdrawandroid) software defined radio app. It doesn't even play the audio and still need to figure out threading. But hey, it shows the waterfall and spectrum and that's all I was going for. It's also only tested on a Pixel 7a running GrapheneOS and you will need a rtlsdr dongle from rtl-sdr.com
